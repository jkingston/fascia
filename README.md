# Fascia

A developer kit for the PF1007L photo fascia: Linux, a touchscreen launcher and a native Zig UI SDK.

![Clock showing a photograph from NASA's Image of the Day feed](docs/clock.png)

<sub>Photo: [ESA/Webb, NASA & CSA, L. Furtak, S. Fujimoto](https://www.nasa.gov/image-detail/galaxies-in-a-cosmic-house-of-mirrors/), cropped by Clock.</sub>

Boots from microSD, leaving Android intact. Includes Clock and Counter example apps.

[Install](docs/install.md) · [App development](docs/app-dev.md)

Experimental: PF1007L PL5 / Allwinner A33 only; fresh-card boot testing is pending.
